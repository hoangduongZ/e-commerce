Giữ module độc lập ngay từ đầu,
để sau này nếu cần tách thành microservice,
ta tách dễ hơn và ít phải viết lại logic.

tác dụng boundary rule
```
- Code ít rối
- Dễ test từng module
- Dễ thay đổi logic nội bộ
- Giảm coupling
- Tránh business logic bị rải lung tung
- Sau này dễ tách microservice nếu cần
```
