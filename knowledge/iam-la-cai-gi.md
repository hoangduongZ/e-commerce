# IAM là gì?

**IAM = Identity and Access Management**

Nghĩa là:

> Module quản lý **người dùng là ai** và **người đó được phép làm gì** trong hệ thống.

---

## 1. Identity = Danh tính

Trả lời câu hỏi:

```text
Bạn là ai?
```

Ví dụ:
```
User: hoang@example.com
Role: ADMIN
User ID: 1001
```

Các chức năng thường có:
```
Đăng ký
Đăng nhập
Quản lý user
Đổi mật khẩu
Refresh token
```
